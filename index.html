How to use this tool

Algorithm: Choose Prim or Kruskal. For Prim, also choose the start vertex s.

Run step: Advance the algorithm by one step. Auto run: Run the algorithm automatically at a fixed speed. Reset: Go back to the initial state of the current graph.

New Random Graph: Generate a random connected weighted graph using the selected node count and density (a random spanning tree plus extra edges).

Graph input: Load an example, load a JSON file, or edit the JSON directly and click Apply. Nodes can be dragged in the graph view.

Prim's algorithm

  • Blue node: start vertex s (before it is extracted).
  • Orange node: the vertex u just extracted from the heap.
  • Teal nodes: vertices already extracted (the set X covered by the tree).
  • Orange ring: the neighbor v whose key is being checked.
  • Thick teal edges: tree edges in T.
  • Thick orange edge: the edge (u, v) being examined.
  • Solid purple edges: the best known connection (pai[v], v) of each vertex still in the heap.
  • Dashed purple edges: other edges crossing the cut (X, V − X).
  • Faded dashed edges: edges with both endpoints in X that are not in T (they can no longer be chosen).
  • The label above each node shows key[v]. Ties in the heap are broken by smaller key, then alphabetical label.

Kruskal's algorithm

  • Node colors: vertices with the same color belong to the same component (same Union-Find root). Vertices that are still alone are left uncolored.
  • Thick orange edge: the edge currently being considered.
  • Thick teal edges: accepted edges (in T).
  • Faded red dashed edges: rejected edges (both endpoints already in the same component, so they would create a cycle).
  • The sorted edge list below the graph shows the status of each edge: pending, current, accepted, rejected, or not examined (after the tree is complete).
  • The Union-Find table shows pai[v] and rank[v]; the forest drawing shows the same parent pointers. Union is by rank (on ties, the root of u becomes the parent) and Find uses path compression. Edges are sorted by weight, keeping the input order for ties.

URL parameters

?algo=prim or ?algo=kruskal preselects the algorithm; ?example=aula, clrs, ties or sparse preselects an example graph. Both can be combined, e.g. ?algo=kruskal&example=clrs.
